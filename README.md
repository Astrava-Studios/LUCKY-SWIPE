# LUCKY-SWIPE

LuckySwipe is a web and mobile app for picking Spanish lottery numbers by swiping through suggested combinations. Swipe right to save a combination, swipe left to pass. The app learns from your swipes to order future suggestions. It makes no promise of improving your chances of winning.

- **Website:** [luckyswipe.app](https://luckyswipe.app)
- **Languages:** Turkish, English, Spanish

## Supported games

Lotteries run by SELAE and ONCE (Spain): Bonoloto, Primitiva, Euromillones, El Gordo, Eurodreams, Lototurf, Eurojackpot, Super 11, Cupón Diario, Cuponazo, Sueldazo, Triplex and Dupla.

## Features

- Swipe-based number selection with a daily limit
- Saved numbers with a scannable QR code
- Sign-in with email or Google, and password reset
- Profile, preferences and reminders
